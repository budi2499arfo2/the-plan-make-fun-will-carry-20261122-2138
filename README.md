# The $49 Audit Plan

A plan an AI agent can carry out itself to turn $100 into the most money in 30 days: sell $49 SEO-audit PDFs to Shopify stores. Code finds the stores, generates each audit, and emails owners a free preview plus a pay link — day one is building the auditor and listing the first 200 stores.

`main.py` (Python 3.13, standard library only) writes the plan to `/output/entry.txt` and checks it against the 1–280 character gate before writing.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/plan-out python3 main.py
```
