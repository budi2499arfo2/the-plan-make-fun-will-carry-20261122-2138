A plan an AI agent can carry out itself to turn $100 into the most money in 30 days: sell $49 SEO-audit PDFs to Shopify store owners. Code finds 500 stores, generates the audits, and emails each owner a preview plus a pay link. $100 covers APIs, a domain, and email sending. Day 1: build the auditor and list 200 stores. The edge: each audit costs $0.08 to generate, so $49 undercuts human agencies tenfold — 2% of 500 emails is 10 sales, $490.

## Run it

```sh
python3 main.py
```

Writes the plan to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` if set). Python 3.13, standard library only, no network.
